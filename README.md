## 1. Conceptos Core

### MLOps (Machine Learning Operations)
Conjunto de prácticas y herramientas que combinan el desarrollo de modelos de Machine Learning y las operaciones de TI para automatizar el ciclo de vida completo de un modelo (extracción de datos, entrenamiento, despliegue y monitoreo continuo). 

> *Nota:* El detalle extendido de MLOps se aborda en otro espacio del programa.

### CI/CD (Continuous Integration / Continuous Deployment)
* **CI (Integración Continua):** Práctica de integrar frecuentemente el código en un repositorio compartido, donde cada push dispara la ejecución automática de compilaciones y pruebas unitarias.
* **CD (Despliegue Continuo):** Automatización de la liberación de código validado a entornos de pruebas o producción sin intervención manual.

### CORS (Cross-Origin Resource Sharing)
Mecanismo de seguridad que emplean los navegadores para autorizar o denegar solicitudes HTTP generadas desde un origen (dominio, puerto o protocolo) distinto al del servidor que sirve los recursos.
